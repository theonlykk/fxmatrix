### 3.4 The event loop: per tick, in this order

1. **Rollover:** if this tick crosses a server midnight, for every open
   simulated position add `points * mult * SYMBOL_TRADE_TICK_VALUE * volume`
   (points by side, from `swaps.csv` for the date that just began) to its
   swap and update `Grind_CarryTestSetPosition`.
2. **Interval flags:** `BREAKER_GATED` active -> `g_grind_breaker_enabled = true; g_grind_breaker_gated = true;`
   else both false. `API_SOFT_WARN` active -> `Grind_ApiLimitsSet(1000000, 1)` else
   `Grind_ApiLimitsSet(1000000, 999000)`.
3. **Market:** `Grind_MarketTestSeed(bid, ask, ...)`, `Grind_MarketTestSeedTimeMsc(t)`,
   `Grind_CarryTestSeedTick(t / 1000, bid, ask)`, `g_grind_carry_test_server_time = t / 1000`,
   `Grind_LatticeTestAddTick(t / 1000, bid, ask)`. Set
   `g_grind_last_feed_tick_msc` to the live `SymbolInfoTick` time so A14's
   stale check never fires on the live clock (A14 is a live-feed guard, not
   a rule of the replay).
4. **Fills:** every order in the seam book placed BEFORE this tick fills at
   its own price if `ask <= price` (BUY_LIMIT) or `bid >= price`
   (SELL_LIMIT). Fills on one tick are processed in placement order. Each
   fill: remove the order from the seam book; a new position id (from
   900000001 up; deal tickets from 800000001 up; never in the seam's 9000
   range); append an IN deal record (comment = the order's comment, magic,
   EURUSD, price, time = `t / 1000`); register the position (A7, A8,
   `Grind_CarryTestSetPosition(id, 0, 0.01, t / 1000)`); write it to the
   deals output; then `Grind_ProcessDeal(...)` with the segment's dials.
5. **Tick sequence (A2):** S3 check; `Grind_ProcessCloseByQueues(magic, false)`;
   `Grind_LatticeOnTick(magic, "OPT", 0.01, lattice, exit_l, add_l, cap, false, t / 1000, exit_s, add_s, reroll, gate)`;
   `Grind_OnTickEngine(magic, "OPT", width_l, exit_l, add_l, stranded, deadband, cap, 0.01, width_s, add_s)`.
   Invariants, quarantine, ejection, session and the breaker's own tick
   are NOT called (replay-calibration s9).
6. **Close-by:** for every task the queue held before step 5 and no longer
   holds after it (a DONE send), the two positions close: two OUT_BY deal
   records (same order ticket, time `t / 1000`, price = each position's
   open price; `profit` = the pair's price P&L at 0.01 lot, half on each;
   `swap` = each position's accrued swap), both written to the deals
   output, both positions removed from every seam list, then
   `Grind_ProcessDeal` on each.
7. **Timer:** if `t` is at least 60 s past the last timer call (or none has
   run), `Grind_CarryOnTimerStep(_Symbol, magic, exit_l, carry, t / 1000, exit_s)`.
8. **Drain:** move every `g_grind_archive_queue` item and every queued scalp
   event to the events output stamped with `t`; empty the queue.
9. **Prune** the lattice tick list to ticks at or after `t - 300 s`, except
   preloaded ticks not yet reached by a side's tracking (s3.3.3). **Loud
   check (GH-3):** whenever a side's `g_grind_vl_tracking_*` goes from false
   to true, its `g_grind_vl_from_msc_*` must be at or after the oldest tick
   still in the list; otherwise print `RPL|ABORT|LATTICE_HISTORY` with both
   times and stop the run (the replay never silently loses history).

### 3.5 Sync mode (replay-calibration s6 T1; input `InpSync = true`)

Before each tick, every real deal (`real_<tag>.csv`) with `time_ms <= t`
not yet applied is applied in order to a TRUE book (IN opens a position,
OUT_BY closes one). After applying any, reset the replay to it:
(a) every replay position not in the true book is removed with its layer
and its exit order; (b) every true position missing from the replay is
added as in s3.3.3 (seed); (c) a true layer keeps its replay exit order if
one rests with its side and layer index; (d) add and L0 orders are kept;
(e) `sync_idx` = the index of the last applied real deal, written on every
later output row. The engine re-places missing exits and moves stale adds
on the next tick by its own rules.

### 3.6 Outputs (`MQL5\Files\replay\out_<tag>_*.csv`)

- `deals`: `seg_id,sync_idx,time_ms,deal,order,position,entry_type,deal_type,role,side,layer,price`
- `events`: `seg_id,sync_idx,time_ms,kind,code,json` (kind `ea_event` or `scalp`)
- `book`: at each segment end: `seg_id,side,layer,entry,vl,open_ms,swap`
- `summary.txt`: per segment ticks read, fills, scalps, roll closes,
  `ROLL_ACCEPTED`, aborts, run time; the GV counts of S4.
