## PREMISE VERDICT

The core idea — stop reserving exit slots for far adds that cannot fill soon — is mechanically sound and directly addresses the double-counting of G2. However, the proposal as specified is **not safe**:

- **T-4** is a material cost: holding adds guarantees missed fills on gaps, and ADR-013 does not “fill at market”; it places a passive limit on the far side of the move.  
- **T-2** shows the proposed H/C defaults can blow the 2,000/day API ceiling with only a few oscillating adds.  
- **T-1** shows the fill-to-next-add path is not same-tick; fast adverse moves can outrun placement.  
- **T-6/T-8** show P6 is false: proximity does not remove contention, so a priority rule is still needed.  
- **P5 defaults** are not defensible without a minimum re-evaluation interval and much larger hysteresis.

The premise survives only with amendments: a priority/tie-break under the fleet lock, a hard API stop, a much larger C or interval, and an explicit gap policy. The proposed defaults do not.
