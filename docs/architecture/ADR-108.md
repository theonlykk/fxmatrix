# ADR-108: Bundled HALT_30 Grid-Boundary Guard + Zero-Rollover Spread Allowance

## Status

Accepted — implemented locally, Tier 1 partial pass (596/604), Cases 3/5 authorized red (Problem 3).

## Context

ADR-107 shipped a rollover-shifted point-estimate for HALT_30 (`expected_adj = naive ± exit_pips + MaxPossibleRolloverShift`, tight 2pt band). Tier 1 real-data testing then surfaced two distinct issues:

### 1. Latent grid-cancellation vector (DeepSeek Phase 1 Round 2)

When `max_shift` approaches one grid step (~88–92pt at default `AddPipsFloor=9.0`), the existing 2pt band alone passes a mis-paired adjacent layer — the Round 1 grid-cancellation vector restored by the rollover term alone, independent of any spread allowance. DeepSeek R2 verified: with `T = base_tol + spread_allowance`, a hold accruing ~82pt rollover drift plus an 8pt spread allowance recreates the exact 90pt masking zone.

### 2. Execution-noise false positives (Problem 2)

Genuine, correct EA fills on 0-midnight (zero-rollover) pairs deviate 2–7pt from the exact model — pure execution noise (spread capture, slippage, requote deadband). 10 of 11 Case 2/3/5 HALT_30 failures were this class under ADR-107. An unconditional spread allowance was rejected (DeepSeek R2: compound path with rollover reopens grid-cancellation).

## Decision

Bundle two structural fixes in `V2_SRE_HedgePriceIndicatesCrossPair`, operating on the same boundary math:

### A. Grid-boundary fail-closed guard

```
G       = V2_SRE_PipsToPrice(add_pips_floor, point)   // derived, not hardcoded
base_tol = V2_SRE_ExitPriceTolerance(point) * 4.0      // 2 points
margin   = point                                       // 1 point

if (max_shift >= G - base_tol - margin) → halt (cross-pair)
```

Fires at ~87pt on default 9-pip grid, before the [88, 92] danger zone where a mis-paired adjacent layer would pass under the 2pt band alone.

### B. Zero-rollover-gated spread allowance (Option B, fixed nominal)

```
rollover_units = V2_SRE_CountRolloverMultiplierUnits(entry_open_time, hedge_open_time)

noise_allowance = (rollover_units == 0)
    ? V2_SRE_NominalSpreadPoints(symbol) * point
    : 0.0

halt if |hedge_open_price - expected_adj| > base_tol + noise_allowance
```

Nominal spread constants (compile-time, points not pips — NOT live market data):

| Symbol | Points | Basis |
|--------|--------|-------|
| EURUSD | 10 | ~1.0 pip typical FTMO demo |
| GBPUSD | 15 | ~1.5 pips typical |
| EURGBP | 15 | ~1.5 pips typical (wider cross) |

`add_pips_floor` threaded from `V2SREOnInitSideConfig` through `V2_SRE_MapHedgeToEntry`.

### Accepted limitation — Problem 3 (availability, not security)

Overnight/long-hold historical CloseBy pairs with genuine 2–7pt execution-noise residuals remain fail-closed under the strict 2pt band. The zero-rollover spread gate deliberately excludes them to preserve the anti-tampering guarantee (no compounding of rollover drift + spread allowance). This overlaps Problem 3 territory (long-hold `MaxPossibleRolloverShift` over-prediction, e.g. Case 5 outlier 508408618/508481504 with 29pt residual over 8 midnights — correctly still halts).

Cases 3/5 long-side Tier 1 failures are **authorized red**, documented in ARCHITECT.md Parked Backlog, blocked-on-Problem-3 — not a security regression.
