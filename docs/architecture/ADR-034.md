# ADR-034 — Exit Spread Sign Inversion in InvertSpreadToPrice

**Status:** Accepted

## Context

ComputeExitPrice passes is_exit=true to InvertSpreadToPrice.
The direction flip at the bottom of the function correctly changed
BUY to SELL, but price was already computed using the original entry-
side T. A BUY position with negative T produced an exit price below
anchor — IsPassive rejected it as a SELL limit below market, returning
-1.0 and holding the position indefinitely.

## Decision

Invert T with T = -T as the first statement inside
InvertSpreadToPrice when is_exit=true, before any routing branch
computes price. This ensures the exit price is computed on the
opposite side of the anchor from the entry.

## Consequences

Exit limits placed on correct side of market.
ComputeExitPrice no longer returns -1.0 under normal conditions.
ADR-031 log-and-return becomes a genuine edge case rather than the
default path. Direction flip block at bottom unchanged.
