**Status:** Accepted — fix implemented and locally committed (2026-08-07).

**Date:** 2026-08-07
**Builds on:** ADR-106 (SRE implementation), DeepSeek Phase 1 HALT_30
audit Round 1 (`prompts/deepseek_phase1_round1_halt30_response.md`,
2026-08-07)
**Related audit:** DeepSeek rejected wide-interval Path A; Gemini approved
point-estimate replacement with tight `point*2` tolerance.

---

## Background

Tier 1 real-data replay surfaced `HALT_30_CLOSEBY_PRICE_INCONSISTENT` on
historical, already-settled CloseBy pairs during reconstruction of unrelated
open stacks. Root cause: `V2_SRE_HedgePriceIndicatesCrossPair` compared hedge
open prices against a naive exit formula (`entry ± exit_pips`) with a
`point*2` tolerance and no rollover term. Positions held across broker
midnights drift by accumulated swap — a drift already modeled elsewhere in
the same file (`V2_SRE_MaxPossibleRolloverShift`,
`V2_RolloverShiftedExitPrice`) but never applied to this historical-pair
check.

DeepSeek Phase 1 rejected the original wide-interval Path A (band
`[expected, expected + max_shift]`) as reopening a cross-pairing blind
spot when rollover shift approaches one grid step. Gemini approved a
point-estimate replacement: center the existing tight `point*2` tolerance
on a rollover-corrected expected price, with the rollover window ending at
`hedge_open_time` (not reconstruction-time `now`).

---

## Decision

1. **HALT_30 math fix (Path A revised):** Extend
   `V2_SRE_HedgePriceIndicatesCrossPair` with `entry_open_time`,
   `hedge_open_time`, and `symbol`. Compute:
   - `expected = V2_SRE_ExpectedExitPrice(paired_entry_price, direction,
     exit_pips, point)`
   - `max_shift = V2_SRE_MaxPossibleRolloverShift(entry_open_time,
     hedge_open_time, symbol, direction, point)`
   - `expected_adj = V2_RolloverShiftedExitPrice(expected, max_shift,
     direction)`
   - Halt when `|hedge_open_price - expected_adj| >
     V2_SRE_ExitPriceTolerance(point) * 4.0` (unchanged 2-point band).
   - Remove naive `HedgePriceConsistentWithEntry` early escape; single
     threshold against `expected_adj` preserves original pass/halt bands
     while correcting the center for overnight drift.
   - Do **not** use `DEAL_SWAP`. Do **not** widen tolerance. Do **not** use
     interval band. Do **not** use `now` as rollover endpoint.

2. **API surface:** Add `symbol` parameter to `V2_SRE_MapHedgeToEntry`;
   production passes `cfg.symbol` from `V2SREOnInitSideConfig`
   (`fxmatrix_v2_sre_oninit.mqh`).

3. **Case 7 test correction:** At flat-at-anchor reconstruction
   (`cfg.now = 2026.08.02 21:20:00`), `FindAnchor` returns the CloseBy
   bucket time; all deals are at or before anchor, so `map_result.pairs` is
   legitimately empty. The original test assertion was over-specified.
   Test now asserts empty pairs at flat anchor and validates mapping with a
   pre-close anchor probe (`2026.08.02 21:00:50`).

## Open Finding: Model-vs-Fill Deviation (Cases 2/3/5)

Cases 2, 3, and 5 still halt with `HALT_30_CLOSEBY_PRICE_INCONSISTENT`
after this fix. Simulation against the Tier 1 deal arrays shows residuals
of **3–13 points** (0.3–1.3 pips) between hedge open prices and
rollover-adjusted expected prices — including **same-day pairs with zero
midnights** where `max_shift = 0` and the check reduces to the original
naive comparison.

This is **distinct** from the overnight rollover false-positive this ADR
fixes. That class (swap drift on multi-night holds) is addressed by
centering on `expected_adj`; Cases 2/3/5 expose a separate
model-vs-execution gap where real fill prices deviate from the modeled exit
by more than the tight 2-point security band even when rollover shift is
correctly applied or zero.

**Tolerance widening is explicitly ruled out** for this control (DeepSeek
Round 1 security finding; Gemini ruling). A **diagnostic pass is authorized**
(as a separate task) to determine whether these residuals are normal
execution artifacts (spread, slippage, partial rollover adjustment timing)
or genuinely irregular trades requiring a supplementary discriminator — not
a wider band.

## Consequences

- Overnight rollover false positives on historical CloseBy pairs: fixed for
  sides that now pass (Cases 1, 4, 6, 7).
- Cross-pairing detection preserved: synthetic cross-pair test unchanged;
  point estimate avoids wide-interval blind spot DeepSeek identified.
- Cases 2/3/5 remain blocked on Tier 1 regression gate until the open
  finding is resolved or ruled benign.
- Deployment remains gated per ADR-106 authorization scope.
