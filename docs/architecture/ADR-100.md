# ADR-100 — EUR-Side Cross-Instance Exposure Cap (EURUSD + EURGBP)

**Status:** Accepted (infrastructure only — both thresholds **0/off**, not deployed)

**Date:** 2026-07-30

---

## Context

ADR-092 introduced a GBP-side cross-instance exposure cap across **GBPUSD + EURGBP**, using MT5 terminal Global Variables (GVs) so each chart publishes its own layer counts and reads peer counts. Net GBP exposure:

```text
GBP_net = (L_GBPUSD - S_GBPUSD) - (L_EURGBP - S_EURGBP)
```

EURGBP long is **short GBP**, so EURGBP layers **subtract** from GBPUSD exposure — the asymmetric delta (+1/−1/−1/+1) in `fxmatrix_v2_gbp_cap.mqh`.

This ADR adds the **mirror mechanism for the shared EUR leg** across **EURUSD + EURGBP**:

```text
EUR_net = (L_EURUSD - S_EURUSD) + (L_EURGBP - S_EURGBP)
```

**Sign convention confirmed by DeepSeek** via direct trace of `ComputeOfferSignal` / `ComputeBidSignal`: long EURGBP is long EUR (reinforces EURUSD exposure), unlike long EURGBP being short GBP. EURGBP deltas are **symmetric** (+1 long, −1 short for both EURUSD and EURGBP).

### Review findings (DeepSeek + Gemini)

| Finding | Resolution |
|---------|------------|
| **A — Sign convention** | Addition, not subtraction — confirmed correct |
| **B — Separate trigger counters** | `V2EUR_CAP_TRIGGERS` distinct from `V2GBP_CAP_TRIGGERS` |
| **C — Silent-omission risk (EURGBP)** | Composite `V2_SyncAllCaps()` replaces individual sync calls at all four layer-mutation sites + OnInit |
| **D — Early-return masking (EURGBP)** | Combined `V2_AnyCapBlocksNewAdd()` evaluates **both** caps separately, logs **both** outcomes, records block on whichever fired |
| **E — No premature generalization** | Composite/combined helpers are **EURGBP-specific** (hardcoded dual participant), not a generic multi-pair dispatcher |

**GBPUSD (`fxmatrix_v2.mq5`) does not participate in the EUR cap** — zero changes. `fxmatrix_v2_gbp_cap.mqh` reused **unmodified**.

Both new thresholds default to **0 (off)** — infrastructure only, no calibration decision.

## Decision

### 1. New module: `ea/fxmatrix_v2_eur_cap.mqh`

Mirrors `fxmatrix_v2_gbp_cap.mqh` structure with EUR-specific keys and math:

| GV key | Role |
|--------|------|
| `V2EUR_L_EURUSD` | EURUSD long layer count |
| `V2EUR_S_EURUSD` | EURUSD short layer count |
| `V2EUR_L_EURGBP` | EURGBP long layer count |
| `V2EUR_S_EURGBP` | EURGBP short layer count |
| `V2EUR_CAP_TRIGGERS` | EUR cap block counter (separate from GBP) |

Functions: `V2_EurNetExposure()`, `V2_EurCapDeltaForAdd()`, `V2_EurCapReadLayers()`, `V2_EurCapPublishLayers()`, `V2_EurCapSyncInstance()`, `V2_EurCapBlocksNewAdd()`, `V2_EurCapRecordBlock()`.

Missing peer GV → layer count **0** (permissive default preserved).

Publish model: **recompute-and-overwrite** from `ArraySize(g_*_layers)` at each sync call — same self-correcting pattern as GBP cap (see GV lifecycle analysis 2026-07-29).

### 2. EURGBP dual-cap helpers: `ea/fxmatrix_v2_eurgbp_dual_cap.mqh`

EURGBP-specific (not generic):

- **`V2_SyncAllCaps(is_long, layer_count)`** — calls both `V2_GbpCapSyncInstance("EURGBP", …)` and `V2_EurCapSyncInstance("EURGBP", …)`
- **`V2_EvalBothCaps(…)`** — evaluates both block checks without short-circuit; builds dual-outcome log string (test-visible)
- **`V2_AnyCapBlocksNewAdd(is_long, gbp_threshold, eur_threshold)`** — logs both cap evaluations always; records `V2_GbpCapRecordBlock()` and/or `V2_EurCapRecordBlock()` for whichever blocked; returns OR aggregate

### 3. Wiring

| File | Changes |
|------|---------|
| `fxmatrix_v2_eurgbp.mq5` | `#include` eur_cap + dual_cap; `InpEurCapThreshold=0`; four layer sites → `V2_SyncAllCaps()`; OnInit → `V2_SyncAllCaps()` + `V2EUR_CAP_TRIGGERS` reset; EnsureAddNext → `V2_AnyCapBlocksNewAdd()` |
| `fxmatrix_v2_eurusd.mq5` | `#include` eur_cap; `InpEurCapThreshold=0`; single-cap wiring mirroring GBPUSD's GBP pattern: sync at Append/Remove/OnInit, gate in EnsureAddNext, `V2EUR_CAP_TRIGGERS` reset on OnInit |
| `fxmatrix_v2.mq5` | **Untouched** |
| `fxmatrix_v2_gbp_cap.mqh` | **Untouched** |
| All `_ref` files | **Untouched** |

### 4. Unit tests (`fxmatrix_v2_tests.mq5`)

**Note:** No prior GBP cap unit tests existed in `fxmatrix_v2_tests.mq5` — EUR cap threshold tests establish the first cap-specific test pattern in this suite.

New test groups (ADR-100):

| Test | Assertions |
|------|------------|
| `Test_EurCapNetExposureAddition` | Addition math; differs from subtraction; long-only; short-only |
| `Test_EurCapDeltaSymmetric` | EURUSD/EURGBP ±1 deltas; GBPUSD delta zero |
| `Test_EurCapBlocksNewAddThreshold` | threshold 0 off; exact landing; widening block; EURGBP path |
| `Test_AnyCapBlocksNewAddNoMasking` | GBP-only block + dual log; EUR-only block + dual log; aggregate OR |
| `Test_SyncAllCapsPublishesBothGvSets` | Both GBP and EUR GV keys published for long and short |

**Compile/run (2026-07-30):** `319/319 passed` (0 errors, 0 warnings).

Critical no-masking test (`Test_AnyCapBlocksNewAddNoMasking`) verifies eval log contains **both** `GBP cap:` and `EUR cap:` lines with correct blocked=true/false for each side when only one cap fires.

## Failure modes closed

1. **Silent omission** — EURGBP layer mutation without one cap's sync → prevented by mandatory `V2_SyncAllCaps()` at all four sites + OnInit.
2. **Early-return masking** — GBP check blocking before EUR check runs → prevented by `V2_AnyCapBlocksNewAdd()` evaluating and logging both before returning.

## Failure modes NOT addressed (inherited from GBP cap)

Restart with open positions while layer arrays empty → OnInit publishes **0** to own GVs before orphan halt (falsely-low peer read). Operational rule: reattach **flat**. Same as GBP cap GV lifecycle.
