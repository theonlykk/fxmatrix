# ADR-049 — OnTradeTransaction Magic Number Filter

**Status:** Committed

## Context

OnTradeTransaction is a global MT5 broadcast — without magic filter both instances process each other's fills. Caused pod halt on 2026-06-26 when SNIPER received MM exit fill it couldn't match in its inventory.

## Decision

Early-exit magic number filter at top of OnTradeTransaction — drop any DEAL_ADD event whose magic is not EA_MAGIC, EA_MAGIC+1, or EA_MAGIC+2 for this instance.

## Consequences

Each instance processes only its own fills; cross-instance inventory corruption prevented; magic=0 manual trades still pass through.

## Negative Space

Existing DEAL_ENTRY_IN/OUT magic checks retained as secondary validation; no other handler changes.
