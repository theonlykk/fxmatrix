# ADR-037: SkewFloor0 Signal Gate — Wash Trade Preventer

**Status:** Accepted

## Context

When `abs(entry_spread) < SkewFloor0`, `floor_skew` dominates `effective_skew`, clamping it to 0.99 and producing `exit_spread ~= entry_spread`. This generates wash trades — entry and exit at virtually identical prices. Live log confirmed: `entry_spread=-0.000140`, `exit_spread_tgt=-0.000138`, `floor_skew=8.57` clamped to 0.99.

## Decision

Add signal strength gate to Option A: if `abs(inst_spread) <= SkewFloor0`, skip quoting with `continue`. Gate fires after existing inventory/pending check. Prevents entry when geometric space for a profitable exit does not exist. SkewFloor0 also lowered from 0.0012 to 0.0002 via input parameter (no code change required).

## Consequences

- Option A refuses to quote on weak signals.
- Wash trades eliminated.
- Option B layering unaffected.
- SNIPER mode unaffected.
- Matrix only quotes when signal supports meaningful exit capture.
