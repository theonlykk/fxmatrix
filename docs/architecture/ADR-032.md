# ADR-032 — Fix Inverted Option A Spread Operators + ADR-013 Passivity Pre-Check

**Status:** Accepted

## Context

Option A bid_spread and offer_spread were computed with 
inverted operators (bid = inst_spread + QuoteSpread, offer = 
inst_spread - QuoteSpread). This placed the bid above market and 
offer below market for all signal directions. ADR-013 then clamped 
both to top-of-book, collapsing a 55-pip theoretical bracket to a 
4-pip crossed box. Additionally ADR-013 fired unconditionally, 
dragging already-passive distant quotes to top-of-book unnecessarily.

## Decision

Swap operators: bid = inst_spread - QuoteSpread, offer = 
inst_spread + QuoteSpread. Add passivity pre-check to ADR-013: only 
clamp BUY when theoretical >= current_bid, only clamp SELL when 
theoretical <= current_ask. Already-passive quotes are left untouched.

## Consequences

Option A bracket correctly placed away from market on 
both sides. ADR-013 only fires when genuinely needed. Bracket width 
restored to full signal-derived distance. No change to Option B, 
exit logic, or any other component.
