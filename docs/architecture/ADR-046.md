# ADR-046 — Dynamic Spread Cooldown & Exit Decoupling

**Status:** Committed

## Context

Post-shock spread stranding — LDAK dilates instantly, resting limits strand too far from spot; exits also stranded by dilated `entry_spread_raw`.

## Decision

Viscous `g_cooldown_LDAK` high-water mark with `CooldownDecayRate` decay; `ComputeExitPriceDeterministic()` capped at `BaseThreshold`; `RunSpreadCooldownReconciliation()` drags entries toward spot on each bar.

## Consequences

Grid contracts gracefully post-shock; exits remain tight and achievable; capital velocity preserved.

## Negative Space

Live `g_corr`/`g_vratio` unchanged; `ComputeLDAKLotSize()` unchanged; exit orders never touched by drag loop.
