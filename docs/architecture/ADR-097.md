# ADR-097 — Depth-Triggered L0 Spread Easing (GBPUSD Production)

**Status:** Accepted (GBPUSD production calibration locked)

**Date:** 2026-07-27 (implementation); **2026-07-28** (1/3 calibration locked)

---

## Context

When one V2 instance is flat (`n == 0`) and the opposite side accumulates genuine depth, the flat side's L0 quote uses a dynamic half-spread:

```text
dynamic_hs = MathMax(quote_spread + sigma * effective_multiplier,
                      live_spread_price + passivity_buffer_price)
```

`sigma` comes from `V2_FvSigmaFromCloses()` — population standard deviation of **three M5 anchor closes** (30 min, 1 h, 4 h lookback), not return volatility or net directional distance.

**Motivating finding (2026-07-27, real CSV replay):** sigma has **zero memory beyond 4 hours** (only `closes[6]`, `closes[12]`, `closes[48]` participate). Across 19 real heavy-depth episodes (one side reaching 3+ layers) in `truss_crisis`, `q1_2024_chop`, and `full_quarter` GBPUSD windows, episode-mean sigma was often **at or below** the window's own baseline during slow multi-day/multi-week depth builds. Example: 894 h short episode mean 8.26 pips vs window baseline mean 8.11 pips; start spike 41.97 pips → end 3.81 pips. The live formula therefore **does not widen** L0 spread in proportion to opposite-side depth during the exact scenario where easing is desired.

**Rejected alternative — fixed-anchor ramp:** DeepSeek Phase 1 evaluated ramping toward a fixed `dynamic_hs` anchor instead of ramping the multiplier weight on live sigma. Empirical replay on the same 19 episodes: **11 of 19 (58%)** would have produced **upward spread discontinuities** at ramp boundaries. **Decision: multiplier ramp only** — sigma continues to be read live every bar; only its weighting changes.

**Integer-division trap (MQL5):** `opposite_depth`, `InpEaseDepthStart`, and `InpEaseDepthFull` are all `int`. Without an explicit `(double)` cast on the numerator, `(opposite_depth - start) / (full - start)` performs C++-style integer division — e.g. `(3-2)/(5-2) == 0` — so the multiplier would sit at the un-eased value until `InpEaseDepthFull`, then snap. Fix: `(double)(opposite_depth - ease_depth_start) / (double)(ease_depth_full - ease_depth_start)`.

**Scope:** GBPUSD production only (`fxmatrix_v2.mq5`). EURUSD/EURGBP and all `_ref` files untouched.

## Decision

### 1. Production inputs (`fxmatrix_v2.mq5`)

| Input | Production default | Role |
|-------|-------------------|------|
| `InpEaseDepthStart` | **1** | Opposite depth ≤ this → full `InpSpreadMultiplier` |
| `InpEaseDepthFull` | **3** | Opposite depth ≥ this → `InpSpreadMultiplierEased` |
| `InpSpreadMultiplier` | 0.5 | Un-eased multiplier (unchanged) |
| `InpSpreadMultiplierEased` | 0.0 | Floor multiplier at full opposite depth (unchanged) |
| `InpPassivityBuffer` | 0.5 pips | Added to live spread in floor term (unchanged) |

**Calibration history:** Discovery-sample defaults were **2/5** (from the 19-episode analysis). A four-window × four-config threshold sweep (16 GBPUSD backtests, ADR-097 binary throughout) compared no-op (`InpSpreadMultiplierEased = InpSpreadMultiplier`), default 2/5, tighter 1/3, and middle 1/4 across `truss_crisis`, `q1_2024_chop`, `vaccine_rally`, and `full_quarter`.

**Locked calibration (2026-07-28, Gemini approved):** **1/3** replaces 2/5 as GBPUSD production default.

**Rationale — scalp count, not turnover-per-exposure:**

- FXMatrix V2 GBPUSD is a **fixed-target (3 pip), fixed-lot (0.01) churn** business on a $10,000 account. Completed round-trip count is the primary revenue driver when per-scalp economics are stable.
- Across all **16 sweep cells**, **$-per-scalp** (in-test P&L ÷ total exits) ranged **$0.257–$0.302** — no material layer-type or config dependence at 0.01 lots. Maximizing round-trip count therefore maximizes realized revenue without needing a lot-size correction factor.
- **1/3 (tighter)** produced **2,756 total exits** across the four canonical windows vs **2,478 under 2/5 (default easing)** — **+278 scalps (+11.2%)** — without raising **max|net lots|** in any single window (peak exposure unchanged at 0.04–0.07 lots).
- An earlier informal ranking by **P&L ÷ time-avg|net lots|** (turnover-per-exposure) is **retracted**. DeepSeek Phase 1 noted that metric does not bind meaningfully at 0.01 lots on this account size; raw P&L and scalp count are the operative comparators.

**Same-binary no-op baseline:** Threshold-sweep comparisons use ADR-097 binary with `InpSpreadMultiplierEased = InpSpreadMultiplier` (ramp neutralised). The passivity floor (`MathMax` on half-spread) remains active and explains small behavioural deltas vs pre-ADR-097 production; it is not removed by the no-op setting.

### 2. Effective multiplier ramp (flat side only)

When quoting side is flat (`ArraySize(g_*_layers) == 0`):

- Long L0: `opposite_depth = ArraySize(g_short_layers)`
- Short L0: `opposite_depth = ArraySize(g_long_layers)`

```mq5
if(opposite_depth <= InpEaseDepthStart)
    effective_multiplier = InpSpreadMultiplier;
else if(opposite_depth >= InpEaseDepthFull)
    effective_multiplier = InpSpreadMultiplierEased;
else
    double frac = (double)(opposite_depth - InpEaseDepthStart) / (double)(InpEaseDepthFull - InpEaseDepthStart);
    effective_multiplier = InpSpreadMultiplier - frac * (InpSpreadMultiplier - InpSpreadMultiplierEased);
```

When quoting side has open layers, `effective_multiplier = InpSpreadMultiplier` unchanged (Add/Reload/exit geometry untouched).

**Production example (1/3, mult=0.5, eased=0.0):**

| opposite_depth | effective_multiplier |
|----------------|---------------------|
| 0, 1 | 0.500 |
| 2 | 0.250 (midpoint) |
| ≥ 3 | 0.000 |

### 3. Live spread fallback + bar-cadence floor

Runtime self-calibrating spread (no hard-coded per-pair constant):

```mq5
static double g_last_valid_spread_price = -1.0;
long raw_spread_points = SymbolInfoInteger(_Symbol, SYMBOL_SPREAD);
if(raw_spread_points > 0)
    g_last_valid_spread_price = raw_spread_points * _Point;
double live_spread_price = (g_last_valid_spread_price > 0.0)
    ? g_last_valid_spread_price
    : InpQuoteSpread;   // cold-start only
```

Floor (evaluated on M5 bar cadence when signal functions run):

```mq5
dynamic_hs = MathMax(quote_spread + sigma * effective_multiplier,
                      live_spread_price + passivity_buffer_price);
```

### 4. OnInit guard

If `InpEaseDepthFull <= InpEaseDepthStart` or either value is negative: log explicit error, `return INIT_FAILED`. No silent clamp.
