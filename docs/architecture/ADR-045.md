# ADR-045 — Spatial Carry/Rollover Adjustment

**Status:** Committed

## Context

Parked limit orders across rollover accumulate swap costs; grid spatial structure must absorb financing to remain financially equivalent.

## Decision

`RunDailyRolloverReconciliation()` fires at 00:01 broker time; unified drift math — long side drifts up, short side drifts down; only negative carry adjusted; Wednesday 3× multiplier.

## Consequences

Grid self-adjusts daily; `exit_price_fixed` remains source of truth by syncing after each modify; positive carry untouched.

## Negative Space

No PnL cash calculations; no new input parameters; no changes to fill logic.
