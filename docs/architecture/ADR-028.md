# ADR-028 — Decouple Option B Grid Layering from Bar-Close Gate

**Status:** Accepted

## Context

Option B (add_next grid layer placement) was nested inside
the if (new_bar) block, causing add_next tickets to wait up to an
additional 5 minutes after MinLayerIntervalSeconds expired. During
intra-bar volatility spikes this means optimal grid entries are
missed entirely as price mean-reverts before the bar closes.

## Decision

Extract Option B into a standalone for loop running on
every tick, before if (new_bar). Option B requires no signal
computation — it uses only pre-computed inventory state. Option A
fresh quoting and RunSignalOnBarClose() remain bar-close gated.

## Consequences

add_next tickets are placed within one tick of
MinLayerIntervalSeconds expiry. Option A and signal logic unchanged.
Computational overhead negligible (three array size checks per tick).
