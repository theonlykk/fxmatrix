# ADR-043 — Layer 0 Inventory Gate (Ping-Pong Fix)

**Status:** Committed

## Context

Ping-pong bug observed 2026-06-25 — Phase 3 resume quoting unconditionally fired Layer 0 entries while same-direction inventory was still open, reloading directional risk just offloaded.

## Decision

`SameDirectionInventoryExists()` gate on both Phase 3 resume `PlaceEntryLimit()` calls; `position_ticket > 0` as canonical live-position signal per Gemini ruling.

## Consequences

Layer 0 blocked when same-direction inventory exists; new risk routes exclusively through `PlaceNextEntryLimit()` A_n spatial premium; opposite-direction Layer 0 unaffected.

## Negative Space

Flat-instrument new-bar quoting loop untouched; `PlaceNextEntryLimit()` untouched; no new globals or input parameters.
