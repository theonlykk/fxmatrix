# ADR-123: Dumb Straddle Place-Once-and-Wait (Revert Bespoke Re-Quote State Machine)

## Status

Accepted -- 2026-08-28. Gemini ruling (reversion to proven grid idempotence; no
DeepSeek audit required). Implements straddle L0 place-once-and-wait at baseline
c7791af. Not committed until independent verification passes.

## Context

The dumb straddle (`ENTRY_STRADDLE`) posts two passive L0 limits when flat: buy at
mid − width, sell at mid + width. ADR-121/122 layered a bespoke re-quote state
machine on top (`g_straddle_ref_mid`, band drift, goalpost, per-leg attempt gates,
cooldown) to fix one-legged persistence and cancel/replace churn. That machine
regressed twice live:

1. **One-legged persistence (ADR-121):** partial placement advanced the goalpost;
   band gate blocked retry of the missing leg.
2. **Resting-leg churn (ADR-122):** with `ref_mid == 0`, drift was always true;
   the live leg was cancel-then-replaced every tick while the missing leg failed
   marketability on a stale feed.

Root cause: the straddle used `Long_ReplacePendingBuy` / `Short_ReplacePendingSell`
(cancel-then-place) instead of the proven grid idiom ("if our order is already
resting, do nothing"). The signal arm and grid add path ran 500+ trades over two
weeks without churn using per-order deadband inside Replace — but the straddle
bypassed even that via `InpEntryMode == ENTRY_SIGNAL &&` on the deadband gate.

The dumb straddle should **never re-quote**. It posts two limits and waits.

## Decision

Per Gemini ruling:

1. **Place-once-and-wait:** For each flat side, if our L0 leg is NOT already live
   on the book (`!Long_IsOurOrderTicket` / `!Short_IsOurOrderTicket`), compute the
   target (mid ± width, Adr013-clamped) and place ONCE via `Long_PlaceBuyLimit` /
   `Short_PlaceSellLimit`. If already resting, leave it untouched — mirror
   `Long_EnsureAddNext` idempotence (`if add_ticket != 0 && OrderSelect -> return`).

2. **Delete the ref_mid machine entirely:** remove `g_straddle_ref_mid`,
   cooldown globals, `V2_DumbShouldRePlace`, `V2_StraddleLegShouldAttempt`,
   goalpost helpers, and all cancel-then-replace paths from `V2_StraddleL0OnTick`.
   Remove `InpL0RetryCooldownMs` (unused).

3. **KEEP ADR-122 feed staleness guard:** `V2_IsFeedStale` at the top of
   `V2_StraddleL0OnTick`; return immediately if stale (no cancel on staleness).

4. **KEEP marketability skip:** pre-send check buy < ask / sell > bid before
   placement. This is place-validity, not re-quote logic (straddle geometry CAN
   be marketable on fast moves).

5. **T-5 stay-dumb:** no new fill-in-flight / position handoff guard. BCC is the
   backstop (Gemini ruling).

Entry-side only. Adr013 clamp, price-calc helpers, `ENTRY_SIGNAL` arm, exit/
recognizer/SRE/Trigger A/BCC untouched.

## Rejected alternatives

**Option A / B re-quote gating (ADR-122):** ref_established and deadband-on-Replace
schemes still re-quote under some conditions. Superseded by place-once-and-wait.

**Per-order deadband on Replace (ADR-123 candidate from DeepSeek Phase 1):**
unnecessary when the straddle never re-quotes; adds complexity without benefit.

**Fill-in-flight handoff guard (DeepSeek T-5):** rejected per Gemini — stay dumb;
BCC backstops duplicate pending detection.

## Verification

- MetaEditor compile: unified shells + tests — 0 errors / 0 warnings.
- Unit suite: baseline adjusted + T-SL-3,10..15:
  - **T-SL-3:** marketability skip (buy < ask / sell > bid).
  - **T-SL-10/11:** feed staleness pure/harness (ADR-122 retained).
  - **T-SL-12:** resting leg -> no place gate.
  - **T-SL-13:** missing leg -> exactly one place over multi-tick sim.
  - **T-SL-14:** marketability blocks place path.
  - **T-SL-15:** stale feed blocks tick action for both legs.

## Consequences

Positive:
- Churn eliminated by construction (no Replace/cancel-then-place in straddle path).
- Missing leg retried each tick until placed (no band/goalpost gate).
- Proven grid idempotence pattern; minimal moving parts.

Negative / bounded:
- Resting orders do not track mid drift (by design — wait for fill or manual flat).
- Fill-in-flight duplicate pending possible for one tick window; BCC is backstop.
- Failed broker reject retries every tick until success or marketability skip (no
  cooldown — acceptable for place-once semantics on missing leg only).
