# ADR-029 — Marketable Reversion Exception — Magic Number Isolation and State Lock

**Status:** Accepted

## Context

The Marketable Reversion Exception block in HandleEntryFill
placed market hedge orders with req.magic = EA_MAGIC. OnTradeTransaction
routes DEAL_ENTRY_IN with EA_MAGIC to HandleEntryFill, causing the hedge
fill to re-enter HandleEntryFill, see exit_price < 0.0 again, and fire
another hedge immediately. With no state lock on exit_tickets[], this
created an infinite cascade of market hedge orders (20+ orders in seconds).

## Decision

Two-part fix. Part 1: change req.magic to EA_MAGIC + 2 so hedge
fills route to HandleExitFill, not HandleEntryFill. Part 2: add a
hedge_in_flight state lock that checks exit_tickets[] via OrderSelect and
HistoryOrderSelect before firing any hedge, refusing to fire if a hedge
is already live, pending, or filled.

## Consequences

Marketable Reversion cascade eliminated. Hedge fills route
correctly to HandleExitFill. g_inventory arrays remain pristine.
No change to normal exit path, Option A, Option B, or any other logic.
