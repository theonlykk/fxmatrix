# ADR-079 — TEMPORARY: DebugEnableDynamicReanchor (Static-Anchor Trap)

**Status:** TEMPORARY / TEST INFRASTRUCTURE — not a permanent architectural decision

## Problem: Static-Anchor Trap

`ComputeNextLayerPrice()` produces a theoretical `add_next` level anchored to `prev_layer.entry_price` — a fill price from an earlier moment. When the market moves non-monotonically (retrace, gap, or LIFO exit reshuffle), the live book can overrun that static level before placement.

`PlaceNextEntryLimit()` then hands the stale theoretical price to the existing gap-aware passivity clamp:

- **BUY:** `price = MathMin(price, current_bid - min_dist)`
- **SELL:** `price = MathMax(price, current_ask + min_dist)`

The clamp is **correct** — it prevents crossing the spread. But when the static level has been overrun, the clamp discards the entire theoretical grid width and collapses the order to `current_bid - min_dist` (or `current_ask + min_dist`). Hybrid spacing earned at deeper layers is erased in a single placement.

Live log evidence: repeated tight re-quotes at the top of book after static levels were overrun, producing grid compression unrelated to `ComputeGridInterval` spacing.

## Decision: Four-Step Dynamic Re-Anchor

When `DebugEnableDynamicReanchor=true`, intercept **before** the existing clamp (which is **never modified**):

1. Compute `distance = MathAbs(static_price - prev_layer.entry_price)` from the **original** static price.
2. Detect passivity violation using the **same** `min_dist` formula as the clamp (`MathMax(stops_level * point, point)`).
3. If violation: discard static level; recompute from **current** market:
   - **BUY:** `new_price = current_bid - distance`
   - **SELL:** `new_price = current_ask + distance`
4. Hand the (possibly reanchored) price to the **unchanged** clamp block, which still runs unconditionally as the final safety barrier.

When `DebugEnableDynamicReanchor=false` (default): the intercept block never executes; behavior is byte-for-byte identical to pre-ADR-079 production.

## Input

```mql5
input bool DebugEnableDynamicReanchor = false;
```

| Toggle | `false` (default) | `true` |
|--------|-------------------|--------|
| `DebugEnableDynamicReanchor` | Static theoretical price → existing clamp (may compress) | Re-anchor from current market preserving distance, then existing clamp |

## Scope

- **Modified:** `PlaceNextEntryLimit()` price selection only — inserted between `double price = ...` and the existing BUY/SELL clamp block.
- **Unchanged:** The clamp block itself (lines ~432–451 character-for-character), `IsClearOfFreezeLevel`, `IsPassive`, bias backstop, `ComputeGridInterval`, `ComputeNextLayerPrice`, ADR-077/078 toggles.

## Deployment warning

**DO NOT** enable `DebugEnableDynamicReanchor=true` on live or demo deployments without explicit backtest validation. This ADR changes order pricing relative to live spread when static levels are overrun — adjacent to passivity protection and requires measured validation before any production consideration.
