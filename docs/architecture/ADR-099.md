# ADR-099 — Depth-Triggered L0 Spread Easing (EURGBP Production, Ramp + Floor)

**Status:** Accepted (EURGBP production calibration locked **1/3**)

**Date:** 2026-07-29 (implementation); **2026-07-29** (1/3 calibration locked, Gemini approved)

---

## Context

ADR-097 locked depth-triggered L0 spread easing on GBPUSD production (`fxmatrix_v2.mq5`) at **1/3**. ADR-098 locked the same design on EURUSD production (`fxmatrix_v2_eurusd.mq5`) at **1/4** (vol-scale deadband preserved).

EURGBP production (`fxmatrix_v2_eurgbp.mq5`) had **no** depth-triggered easing prior to this ADR. Its L0 signal path uses the **AB-slot triad formula** via `V2_ComputeAbBid` / `V2_ComputeAbOffer`:

```text
inst_spread = r_AC - r_BC
dynamic_hs  = quote_spread + MathMax(sig_ac, sig_bc) * spread_multiplier   // pre-ADR-099
bid         = (fv_ac / fv_bc) * exp(inst_spread - dynamic_hs)
offer       = (fv_ac / fv_bc) * exp(inst_spread + dynamic_hs)
```

Unlike GBPUSD/EURUSD (single-leg BC sigma), EURGBP passes **`MathMax(sig_ac, sig_bc)`** as the volatility term — the dominant leg's sigma drives half-spread width. Staff Architect (Gemini) asked whether this dual-sigma structure survives the easing ramp without corrupting pre-existing swap logic.

### Ramp-without-floor vulnerability (Red Team + Staff Architect)

DeepSeek Phase 1 audit of a **ramp-only** EURGBP prototype found a blocking safety issue: at full opposite depth, `effective_multiplier` can reach `InpSpreadMultiplierEased` (0.0). With zero multiplier weight on sigma:

```text
dynamic_hs = quote_spread + MathMax(sig_ac, sig_bc) * 0.0
           = quote_spread    // bare configured spread only
```

If the **live market spread** has widened beyond `InpQuoteSpread`, the quote can sit **inside** the real spread → guaranteed adverse fills on L0 entry. Gemini independently reached the same conclusion.

**Decision:** Implement **ramp + passivity floor together**, not the ramp alone. The floor is mandatory:

```text
dynamic_hs = MathMax(quote_spread + MathMax(sig_ac, sig_bc) * effective_multiplier,
                      live_spread_price + passivity_buffer_price)
```

Shared helpers already committed via ADR-097 (`fxmatrix_v2_signal.mqh`) are **reused unmodified**:

- `V2_EffectiveSpreadMultiplier`
- `V2_L0DynamicHalfSpread`
- `V2_L0ResolveLiveSpreadPrice`
- `V2_ResolveLiveSpreadPriceFromRaw`

**Scope:** EURGBP production only (`fxmatrix_v2_eurgbp.mq5`). GBPUSD, EURUSD, and all `_ref` files **untouched**. **Repo and local verification only — not deployed to VPS.**

## Decision

### 1. Production inputs (`fxmatrix_v2_eurgbp.mq5`)

| Input | Production default | Role |
|-------|-------------------|------|
| `InpEaseDepthStart` | **1** | Opposite depth ≤ this → full `InpSpreadMultiplier` |
| `InpEaseDepthFull` | **3** | Opposite depth ≥ this → `InpSpreadMultiplierEased` |
| `InpSpreadMultiplier` | 0.5 | Un-eased multiplier (unchanged) |
| `InpSpreadMultiplierEased` | 0.0 | Floor multiplier at full opposite depth |
| `InpPassivityBuffer` | 0.5 pips | Added to live spread in floor term |

**Calibration history:** Discovery-sample defaults were **2/5** (matching GBPUSD/EURUSD pre-lock discovery defaults). A six-config × four-window threshold sweep (24 EURGBP backtests) compared no-op (`InpSpreadMultiplierEased = InpSpreadMultiplier`), discovery **2/5**, tighter **1/3**, middle **1/4**, **1/5**, and **2/6** across `truss_crisis`, `q1_2024_chop`, `vaccine_rally`, and `full_quarter`.

**Locked calibration (2026-07-29, Gemini approved):** **1/3** replaces 2/5 as EURGBP production default.

**Rationale — thin aggregate margin, three-way per-window split:**

- FXMatrix V2 EURGBP is the same fixed-target (3 pip), fixed-lot (0.01) churn model as GBPUSD/EURUSD. Completed round-trip count remains the primary revenue driver when per-scalp economics are stable.
- **Aggregate sweep (four windows):**

  | Config | Total exits | In-test P&L |
  |--------|-------------|-------------|
  | **1/3 (locked)** | **1,128** | **$404.45** |
  | 1/4 (runner-up) | 1,109 | $401.54 |
  | 2/5 (discovery placeholder) | 1,062 | $380.56 |

- **Margin over runner-up 1/4:** +19 exits (**+1.7%**) and +$2.91 P&L (**+0.7%**). The aggregate lead is real but thin — smaller absolute sample sizes than GBPUSD/EURUSD sweeps (EURGBP total exits per config ~1,000–1,130 vs GBPUSD ~2,400+).
- **Per-window exit peaks split three ways** — no single config dominates all windows:

  | Window | Peak config | Peak exits |
  |--------|-------------|------------|
  | `truss_crisis` | **1/3** | 436 |
  | `q1_2024_chop` | 1/5 | 163 |
  | `vaccine_rally` | 1/4 | 452 |
  | `full_quarter` | 1/4 | 106 |

- **Net exposure:** `max|net lots|` held at **0.03–0.04** throughout all sweep configs — tighter than GBPUSD (0.04–0.07) or EURUSD peaks; no exposure escalation from choosing 1/3.
- **Gemini ruling:** The thin aggregate margin is an acceptable **mechanical tie-breaker**, not a blocker. 1/3 wins aggregate exits and P&L, wins the largest window (`truss_crisis`), and matches GBPUSD's locked **1/3** numerically — arrived at independently via EURGBP-specific sweep data, not by copying GBPUSD defaults.

**Same-binary no-op baseline:** Threshold-sweep comparisons use ADR-099 binary with `InpSpreadMultiplierEased = InpSpreadMultiplier` (ramp neutralised). The passivity floor (`MathMax` on half-spread) remains active.

### 2. Inlined AB-slot signal path (ramp + floor)

`Long_ComputeBidSignal` and `Short_ComputeOfferSignal` no longer delegate to `V2_ComputeAbBid` / `V2_ComputeAbOffer`. They inline the full `V2_ComputeAbBidOffer` logic and substitute only the half-spread computation:

**Preserved checks (unchanged from `V2_ComputeAbBidOffer`):**

- `V2_CopyM5Closes` on both legs (≥49 bars)
- `V2_FvSigmaFromCloses` on both legs
- `ac_now > 0`, `bc_now > 0`
- `r_ac`, `r_bc`, `inst_spread`, `ratio = fv_ac / fv_bc`
- Final positivity: `bid_theoretical > 0` / `offer_theoretical > 0`

**Easing wiring (flat quoting side only):**

- Long L0 (`ArraySize(g_long_layers) == 0`): ramp on `ArraySize(g_short_layers)`
- Short L0 (`ArraySize(g_short_layers) == 0`): ramp on `ArraySize(g_long_layers)`
- When quoting side has open layers: `effective_multiplier = InpSpreadMultiplier` unchanged

**Half-spread:**

```mq5
double live_spread_price = V2_L0ResolveLiveSpreadPrice(InpQuoteSpread);
double dynamic_hs = V2_L0DynamicHalfSpread(
   InpQuoteSpread,
   MathMax(sig_ac, sig_bc),          // dual-sigma: dominant leg as sigma stand-in
   effective_multiplier,
   live_spread_price,
   PipsToPrice(InpPassivityBuffer));
bid_theoretical  = ratio * MathExp(inst_spread - dynamic_hs);
offer_theoretical = ratio * MathExp(inst_spread + dynamic_hs);
```

`_Symbol` resolves to EURGBP for live spread lookup — no synthetic AC/BC spread derivation.

**Production example (1/3, mult=0.5, eased=0.0):**

| opposite_depth | effective_multiplier |
|----------------|---------------------|
| 0, 1 | 0.500 |
| 2 | 0.250 (midpoint) |
| ≥ 3 | 0.000 |

### 3. DIAG logging

When `InpVerboseLog` and opposite depth exceeds `InpEaseDepthStart`:

- `event=l0_ease` — logs `sig_ac`, `sig_bc`, `effective_multiplier`, `dynamic_hs` (both legs visible for field diagnostics)
- `event=l0_lag` — resting vs theoretical price, gap in pips, deadband skip (matches EURUSD pattern; EURGBP uses standard deadband without vol-scale ref)

### 4. OnInit guard

```mq5
if(InpEaseDepthFull <= InpEaseDepthStart || InpEaseDepthStart < 0 || InpEaseDepthFull < 0)
   return INIT_FAILED;
```

Explicit error log matching GBPUSD/EURUSD pattern.

## Verification

### Unit tests (`fxmatrix_v2_tests.mq5`)

ADR-099 EURGBP-specific tests exercising shared helpers (pure function coverage, not EA runtime):

| Test | Purpose |
|------|---------|
| `Test_EurgbpAbDualSigmaSwapIndependence` | 9-case matrix: ac>bc, ac<bc, ac==bc × full/mid/eased multiplier — confirms `MathMax(sig_ac,sig_bc)` selection and correct scaling |
| `Test_EurgbpAbFloorRescue` | **Safety-critical:** fully eased + sigma=0 + wide live spread → `dynamic_hs = live + buffer`, NOT bare `quote_spread` |
| `Test_EurgbpEaseDepthOnInitGuard` | Invalid depth inputs rejected; **1/3 production-valid** |
| `Test_EurgbpAbLiveSpreadFallbackWiring` | Cold-start fallback to `InpQuoteSpread`; floor uses resolved live spread |
| `Test_EurgbpAbFlatMultiplierNoRamp` | Quoting-side-with-layers path: flat mult matches legacy sigma formula when floor below |

**Production 1/3 ramp coverage:** `Test_L0SpreadEaseMultiplierRamp_Production13` hardcodes `start=1`, `full=3` on the shared `V2_EffectiveSpreadMultiplier` — the same pair-agnostic function EURGBP calls at runtime via `InpEaseDepthStart` / `InpEaseDepthFull`. No separate `Production15` test required; EURGBP AB tests use hardcoded multiplier constants and do not read EA input defaults.

**Headless run (2026-07-29, lock-in):** **286/286 passed** (0 errors, 0 warnings compile).

**Floor-rescue explicit result:** PASS — `dynamic_hs=0.00085000` equals `live+buffer=0.00085000` (NOT bare `quote_spread=0.00040000`).

**Swap-independence matrix:** 18/18 assertions PASS (9 sigma-path + 9 max-sigma identity checks across all multiplier states).
