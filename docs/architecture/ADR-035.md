# ADR-035 — PlaceNextEntryLimit Gap Clamp min_dist Offset

**Status:** Accepted

## Context

PlaceNextEntryLimit clamped add_next to exactly current_bid
on a gap down (MathMin(price, current_bid)). IsPassive requires strict
less-than, so equality caused passivity failure and add_next stalled.

## Decision

Add min_dist offset mirroring ADR-013 logic. BUY clamps to
current_bid - min_dist, SELL to current_ask + min_dist. min_dist
from SYMBOL_TRADE_STOPS_LEVEL.

## Consequences

Grid placement succeeds after gap events. Strict
passivity always satisfied. Normal path unaffected.
