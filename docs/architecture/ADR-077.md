# ADR-077 — TEMPORARY: ComputeGridInterval Four-Mechanism Decomposition

**Status:** TEMPORARY / TEST INFRASTRUCTURE — not a permanent architectural decision

## Discovery

`ComputeGridInterval()` in `MathEngine.mqh` was a **fully dormant function** with zero live call sites. It bundled four distinct spacing mechanisms into one return value:

| Mechanism | Source | Was in dormant function |
|-----------|--------|-------------------------|
| **Base interval** | GridMode 0/1/2 (constant / linear / hybrid) | Yes |
| **Layer stress** | `LayerStressBase^layer_idx` | Yes |
| **PnL stress** | `GetPodUnrealizedPnL()` + `K_spread` | Yes (when `instrument >= 0`) |
| **LDAK dilation** | `g_cooldown_LDAK[instrument]` | Yes (when `instrument >= 0`) |

Live spacing at both call sites used a **different formula entirely**:

```
base_add = QuoteSpread * (layer_idx + 1)
```

in `ComputeNextLayerPrice()` and `HandleEntryFill()` add_next storage — never `ComputeGridInterval()`.

## Decision

Decompose `ComputeGridInterval()` into four independently toggleable mechanisms via ADR-077 debug inputs. Wire it as a drop-in replacement for the hardcoded `base_add` line at both call sites.

## Inputs (all default `false`)

```mql5
input bool DebugEnableGridMode     = false;
input bool DebugEnableLayerStress  = false;
input bool DebugEnablePnLStress    = false;
input bool DebugEnableLDAKDilation = false;
```

| Toggle | `false` (default) | `true` |
|--------|-------------------|--------|
| `DebugEnableGridMode` | `QuoteSpread * (layer_idx + 1)` — **today's live formula** | GridMode branch via GridBase / GridLinearStep / GridInflection / GridExpBase |
| `DebugEnableLayerStress` | `1.0` (neutral) | `LayerStressBase^layer_idx` |
| `DebugEnablePnLStress` | `1.0` (neutral) | Live-drawdown-linked multiplier via `GetPodUnrealizedPnL()` |
| `DebugEnableLDAKDilation` | `1.0` (neutral) | `g_cooldown_LDAK[instrument]` |

## Neutral-default correctness requirement

When **all four toggles are `false`**, output MUST be **bit-for-bit identical** to:

```
QuoteSpread * (layer_idx + 1)
```

This is **not** the same as GridMode 0 (`GridBase` alone). Enabling GridMode's constant branch without the toggle would silently change live behavior. The `else` branch explicitly preserves today's production formula.

Reasoning proof (all toggles false):

```
base_interval = QuoteSpread * (layer_idx + 1)
layer_stress  = 1.0
pnl_stress    = 1.0
dilation      = 1.0
result        = base_interval * 1.0 * 1.0 * 1.0
              = QuoteSpread * (layer_idx + 1)
```

## Call sites

| Location | Replacement |
|----------|-------------|
| `ExecutionEngine.mqh` — `ComputeNextLayerPrice()` | `ComputeGridInterval(prev.layer_index, instrument)` |
| `ExecutionEngine.mqh` — `HandleEntryFill()` add_next | `ComputeGridInterval(L.layer_index, instrument)` |

Both functions have `instrument` in scope (parameter vs. `GetInstrumentFromSymbol(deal_symbol)`).

## Staged isolation plan (Staff Architect Ruling 2)

1. **Phase A:** Wire with all toggles off — confirm zero live behavior change (this ADR).
2. **Phase B:** Enable `DebugEnableGridMode` alone in backtest — validate GridMode 0/1/2 spacing in isolation.
3. **Phase C:** Enable stress/dilation toggles one at a time after GridMode baseline is validated.
4. **Phase D:** Combined backtest with multiple toggles before any live consideration.

**DO NOT** enable any ADR-077 toggle on live or demo deployments without explicit backtest validation.

## Negative space

- `ComputeKineticDistance()` / kinetic_dist in `ComputeNextLayerPrice` — untouched
- `GetPodUnrealizedPnL()`, `g_cooldown_LDAK[]` computation — read-only reuse
- E_n / A_golden / exit-side formulas — untouched
- Tests 0–52 — unchanged

## Consequences

- Live behavior unchanged at default inputs (hard correctness requirement)
- Dormant Phase 3 grid machinery becomes testable without re-architecting spacing
- Temporary infrastructure pending backtest validation — remove or hard-disable after isolation tests complete
