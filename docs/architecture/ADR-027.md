# ADR-027 — ComputeNextLayerPrice Direction-Aware Grid Step

**Status:** Accepted

## Context

ComputeNextLayerPrice used a direction-blind formula
(entry_spread - S - S*(1-skew)) for the add_next spread calculation.
For SELL positions, subtracting S from entry_spread produces a spread
smaller than entry, which InvertSpreadToPrice translates to a price
below the entry price. This caused the grid layering gate to fire
instantly on every tick for any SELL position, producing a 19-layer
cascade on GBPUSD within 7 seconds.

## Decision

Replace the single formula with a direction-aware branch:
BUY subtracts S (spread narrows, price falls to trigger next layer);
SELL adds S (spread widens, price rises to trigger next layer).
InvertSpreadToPrice is direction-agnostic and correctly translates
the target spread to physical price for all three slots including
synthetic SLOT_AB.

## Consequences

Grid layering fires correctly for both BUY and SELL
positions. No change to InvertSpreadToPrice, slot mappings, skew
logic, or gate conditions. SNIPER mode unaffected (no layering).
