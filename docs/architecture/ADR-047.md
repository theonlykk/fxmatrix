# ADR-047 — Phase 3 Resume: Spread Sign Fix & ADR-037 Weak Signal Gate

**Status:** Committed

## Context

Phase 3 resume had inverted bid/offer spread signs (bid above mid, offer below mid) and no ADR-037 weak signal gate — causing crossed-market pricing and toxic fills after pod close.

## Decision

Fix spread signs to `bid = inst_spread - QuoteSpread`, `offer = inst_spread + QuoteSpread`; add ADR-037 weak signal skip gate before placement.

## Consequences

Phase 3 resume now correctly prices passive limits; weak signal conditions defer to next bar's flat-quoting loop.

## Negative Space

Flat-quoting loop in FXMatrix.mq5 unchanged; ADR-043 inventory checks unchanged.
