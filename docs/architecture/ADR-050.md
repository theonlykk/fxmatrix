# ADR-050 — Fix gross_pnl=0.00 in LAYER_EXIT Logs

**Status:** Committed

## Context

All LAYER_EXIT logs showed gross_pnl=0.00. MT5 attributes realized P&L to DEAL_ENTRY_OUT, not DEAL_ENTRY_IN. Since inventory cleanup happens on DEAL_ENTRY_IN, logging must also happen there — but deal_profit is always 0 at that point.

## Decision

Intercept net P&L via `PositionSelectByTicket(CurL.position_ticket)` + sum of `POSITION_PROFIT` + `POSITION_SWAP` + `POSITION_COMMISSION` just before `LogLayerExit()`, within the single DEAL_ENTRY_IN pass. Falls back to `deal_profit` if position already settled.

## Consequences

LAYER_EXIT logs now show correct realized P&L; single-pass cleanup preserved; no async split across two OnTradeTransaction events.

## Negative Space

`LogLayerExit()` body unchanged; `OnTradeTransaction()` unchanged; no new parameters.
