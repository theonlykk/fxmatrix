# ADR-057 — Kinetic Entry Gate

**Status:** Committed

## Context

The existing `MinLayerIntervalSeconds` time gate is blind to market velocity. During violent macro trends the EA repeatedly adds layers into falling knives — a 71-layer inventory event occurred on 2026-06-29. The time floor alone cannot distinguish consolidation from directional acceleration.

## Decision

Layer a three-component **Kinetic Entry Gate** on top of the retained time floor. All three conditions must pass (in addition to the time gate) before add-next fires:

### Component 1 — Volatility-Scaled Distance (`ComputeKineticDistance`)

- `kinetic_scale = 1.0 + (sigma_pts / KineticSigmaThreshold)`
- `kinetic_dist = GridBase * kinetic_scale`
- Integrated into `ComputeNextLayerPrice()` A_n calculation:
  - `A_n = MathMax(base_add, MathMax(E_n + 10*pt, kinetic_dist))`
- For `SLOT_AB`, uses `MathMax(g_sigma_fv_pts[0], g_sigma_fv_pts[1])` (weakest-link)

### Component 2 — Sideways Validator (`ComputeSyntheticSpreadVelocity`)

- 5-bar (configurable) rolling synthetic spread velocity in pts/bar
- `SLOT_AB`: direct `iClose(AB)` velocity
- `SLOT_AC` / `SLOT_BC`: implied cross `iClose(AC) / iClose(BC)`
- Point scale divisor: `g_symbols[SLOT_AB]` for all slots (uniform cross-asset comparison)

### Component 3 — Inventory-Weighted Patience (`KineticGateOpen`)

- `effective_thresh = MathMax(1.0, KineticVelocityThreshold / inv_size)`
- Gate open when `velocity < effective_thresh`
- Absolute floor of 1.0 pt/bar prevents impossibility at deep inventory

### Gate ordering

1. **Primary:** `MinLayerIntervalSeconds` time floor (unchanged)
2. **Secondary:** `KineticGateOpen(inst, inv_size)` velocity + patience check

Applied in both:
- `HandleEntryFill()` — fill-path add-next
- `FXMatrix.mq5` OnTick Option B — re-arm after sleep expires

## Parameters

| Input | Default | Role |
|-------|---------|------|
| `KineticSigmaThreshold` | 50.0 | sigma_pts where grid spacing doubles |
| `KineticVelocityBars` | 5 | M5 bar rolling window |
| `KineticVelocityThreshold` | 5.0 | max pts/bar before block |

## Consequences

- Grid spacing stretches dynamically in volatile regimes (Component 1)
- Add-next locked until micro-exhaustion confirmed via low synthetic spread velocity (Component 2)
- Deep inventory demands near-flat consolidation before next layer (Component 3)
- Time floor retained — kinetic gate is additive, not replacement
- Live OrderModify tolerance on resting add-next deferred to ADR-057b if observation warrants

## Negative Space

- `MinLayerIntervalSeconds` and `g_last_layer_time[]` unchanged
- `PlaceNextEntryLimit()` body unchanged
- SNIPER expiry (ADR-051) and Layer 0 new_bar quoting unchanged
