# ADR-058 — Directional Sniper Bias

**Status:** Committed

## Context

A single SNIPER instance quotes both directions on Layer 0 (BUY_LIMIT bid + SELL_LIMIT offer). During violent macro trends, both sides can accumulate inventory simultaneously — creating **Basket Lock** risk where opposing pods fight the same move and drawdown compounds without directional clarity.

## Decision

Introduce `ENUM_DIRECTIONAL_BIAS` with three values:

| Value | Layer 0 bid (BUY_LIMIT) | Layer 0 offer (SELL_LIMIT) |
|-------|---------------------------|----------------------------|
| `BIAS_BOTH` | permitted | permitted |
| `BIAS_LONG_ONLY` | permitted | blocked |
| `BIAS_SHORT_ONLY` | blocked | permitted |

### Scope

- **Gated:** Layer 0 entry placement in the new_bar quoting block only (`PlaceEntryLimit` for bid/offer)
- **Ungated:** Exit limit placement (EA_MAGIC+2), add-next / Option B deeper layers, `HandleEntryFill()`, `HandleExitFill()`, SNIPER mode quoting block

Exits (opposite-direction limits for existing inventory) are **always permitted** regardless of bias.

### Implementation

```mql5
enum ENUM_DIRECTIONAL_BIAS { BIAS_BOTH, BIAS_LONG_ONLY, BIAS_SHORT_ONLY };
input ENUM_DIRECTIONAL_BIAS DirectionalBias = BIAS_BOTH;
```

Bid gate: `bid_price > 0 && DirectionalBias != BIAS_SHORT_ONLY`

Offer gate: `offer_price > 0 && DirectionalBias != BIAS_LONG_ONLY`

## Deployment Topology

| Instance | Symbol | Timeframe | EA_MAGIC | DirectionalBias |
|----------|--------|-----------|----------|-----------------|
| MM | EURGBP | M5 | 20260000 | BIAS_BOTH |
| SNIPER LONG | EURUSD | M5 | 20260100 | BIAS_LONG_ONLY |
| SNIPER SHORT | EURUSD | M5 | 20260200 | BIAS_SHORT_ONLY |

Magic numbers and bias are set at attach time — no code-level magic assignment required.

## Consequences

- Directional exposure decoupled across independent SNIPER pods
- Phase 3.B correlated exposure limits can independently suppress LONG or SHORT pod without cross-contamination
- MM instance retains symmetric two-sided quoting (`BIAS_BOTH`)
- Default `BIAS_BOTH` preserves backward-compatible behaviour for existing deployments

## Negative Space

- Exit placement (EA_MAGIC+2) untouched
- add_next Option B block untouched
- SNIPER mode quoting block untouched
- `HandleEntryFill()` / `HandleExitFill()` untouched
- `ENUM_EXECUTION_MODE` and `ExecutionMode` input untouched
