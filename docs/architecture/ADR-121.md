# ADR-121: Straddle L0 Decouple-and-Retry + Dual Guard

## Status

Accepted -- 2026-08-28. Gemini ruling (execution-layer race; no DeepSeek audit
required). Implements straddle L0 reliability fix at baseline aac2a65. Not
committed until independent verification passes.

## Context

On live re-enable with `ENTRY_STRADDLE`, a market-open latency race made a buy
L0 limit marketable by broker receipt (valid at Adr013 clamp time, ~90 points of
adverse move in flight) and the order was rejected. The sell leg placed
successfully. The pre-fix `V2_StraddleL0OnTick` gated both legs behind a single
top-level `V2_DumbShouldRePlace` band check, set `updated=true` if **either** leg
placed, and advanced `g_straddle_ref_mid` on any partial success. After the
failed buy, `V2_DumbShouldRePlace` blocked re-placement until mid drifted past
`InpDumbRefBandPips` — so the missing buy was never retried and the side sat
one-legged. BCC correctly flagged `ONE_LEGGED` every cycle; the persistence
was an entry-layer policy bug, not a BCC false positive.

## Decision

Per Gemini ruling:

1. **Goalpost rule:** `g_straddle_ref_mid` advances ONLY when BOTH L0 legs (buy
   AND sell) are confirmed live on the broker book AND both sides are flat.
   Partial (one-legged) results must NOT advance it.

2. **Per-leg independent retry:** Evaluate each leg every tick. If a leg is
   missing (no live order of ours), attempt placement independent of the
   mid-drift band gate. If live, re-quote ONLY when mid drifted past band.

3. **Anti-spam dual guard** (mandatory, before every straddle L0 OrderSend):
   - **(a) Pre-send marketability:** Re-read current ask/bid; skip buy if
     `clamped_price >= Ask`; skip sell if `clamped_price <= Bid`. Log DIAG on
     skip. No cooldown on marketability skip (nothing was attempted).
   - **(b) Per-side hard cooldown:** On failed placement (`Replace*` returns
     false), set `g_<side>_l0_cooldown_until = GetTickCount64() +
     InpL0RetryCooldownMs` (default 750 ms; Gemini range 500–1000).

Entry-side only. Adr013 clamp math and `V2_DumbShouldRePlace` unchanged.
`ENTRY_SIGNAL` arm untouched.

## Rejected alternatives

**Per-side ref_mid:** Would complicate anti-thrash semantics and diverge from
the shared straddle mid anchor. Rejected.

**Leave one-legged and rely on BCC:** BCC detects correctly but does not repair;
the side remains unable to add until manual intervention. Rejected.

## Implementation

| Change | Location | Summary |
|--------|----------|---------|
| 1 | Unified shells + `fxmatrix_v2_engine.mqh` | `InpL0RetryCooldownMs` input; `g_long_l0_cooldown_until` / `g_short_l0_cooldown_until` globals (`GetTickCount64()`). |
| 2 | `fxmatrix_v2_engine.mqh` | Restructure `V2_StraddleL0OnTick`: per-leg attempt logic, dual guard, goalpost advance. |
| 3 | `fxmatrix_v2_entry_ab.mqh` | Pure helpers for leg attempt, marketability, cooldown, ref_mid goalpost (unit-test target). |
| 4 | `fxmatrix_v2_tests.mq5` | T-SL-1..6 regression tests. |

## Verification

- MetaEditor compile: unified shells + tests — 0 errors / 0 warnings.
- Unit suite: baseline (901/901 post-ADR-120) + T-SL-1..6:
  - **T-SL-1:** Partial placement does not advance `g_straddle_ref_mid`.
  - **T-SL-2:** Missing leg retries without band drift.
  - **T-SL-3:** Pre-send marketability skip — no send, no cooldown.
  - **T-SL-4:** Cooldown blocks then allows after expiry.
  - **T-SL-5:** Healthy two-legged book within band — no churn.
  - **T-SL-6:** Both legs live — ref_mid advances.

## Consequences

Positive:
- One-legged straddle persistence from partial placement + band gate eliminated.
- Market-open race mitigated by pre-send marketability re-check.
- Failed-send spam bounded by per-side cooldown.

Negative / bounded:
- Missing leg may retry every tick while flat (bounded by marketability skip and
  cooldown on actual failed sends).
- Cooldown uses `GetTickCount64()` (64-bit; avoids 49.7-day `GetTickCount()` wrap).
