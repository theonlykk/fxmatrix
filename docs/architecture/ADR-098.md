# ADR-098 — Depth-Triggered L0 Spread Easing (EURUSD Production)

**Status:** Accepted (EURUSD production calibration locked)

**Date:** 2026-07-28 (implementation); **2026-07-29** (1/4 calibration locked)

---

## Context

ADR-097 implemented depth-triggered L0 spread easing on GBPUSD production (`fxmatrix_v2.mq5`) only. EURUSD production (`fxmatrix_v2_eurusd.mq5`) is the pair with the **vol-scale deadband variant** (`InpL0DeadbandVolScale`, `EurUsd_L0DeadbandSpreadRef()`). This ADR ports the same easing design to EURUSD with explicit analysis of how vol-scale interacts — or does not — with the eased `dynamic_hs` path.

**Scope:** EURUSD production only (`fxmatrix_v2_eurusd.mq5`). GBPUSD (`fxmatrix_v2.mq5`), EURGBP, and all `_ref` files **untouched**. **Repo and local Strategy Tester only — not deployed to VPS.**

---

## Step 1 finding — pre-change EURUSD signal path

EURUSD **shares** `fxmatrix_v2_signal.mqh` with GBPUSD (single copy, `#include` in both EAs). It does **not** use the AB-slot triad path (`V2_ComputeAbBidOffer` / `MathMax(sig_ac, sig_bc)`).

Pre-change L0 quoting delegated to BC helpers:

```mq5
bool Long_ComputeBidSignal(double &bid_theoretical) {
   return V2_ComputeBcBid(_Symbol, InpQuoteSpread, InpSpreadMultiplier, bid_theoretical);
}

bool Short_ComputeOfferSignal(double &offer_theoretical) {
   return V2_ComputeBcOffer(_Symbol, InpQuoteSpread, InpSpreadMultiplier, offer_theoretical);
}
```

Inside `V2_ComputeBcBid` / `V2_ComputeBcOffer` (`fxmatrix_v2_signal.mqh`):

```mq5
   double dynamic_hs = quote_spread + sigma * spread_multiplier;
   bid_theoretical = fv * MathExp(r - dynamic_hs);
```

**Vol-scale is deadband-only on EURUSD.** `InpL0DeadbandVolScale` and `EurUsd_L0DeadbandSpreadRef()` (returns `V2_PAIR_SPREAD_PIPS_REF = 0.18` when enabled) are passed only to `V2_L0RestingWithinDeadband()` in `Long_ReplacePendingBuy` / `Short_ReplacePendingSell`. They **do not** enter `dynamic_hs`, sigma computation, or spread multiplier weighting.

There is no `sigma_bc` vol-scaled term in EURUSD production — that naming applies to the AB-slot path used by EURGBP, not EURUSD.

## Vol-scale interaction decision (explicit)

| Mechanism | Affected by easing? | Notes |
|-----------|---------------------|-------|
| `dynamic_hs = quote_spread + sigma * effective_multiplier` | **Yes** | `effective_multiplier` ramps per ADR-097 when flat + opposite depth > start |
| `V2_L0DynamicHalfSpread` floor | **Yes** | Same `live_spread_price + passivity_buffer` floor as GBPUSD |
| `V2_L0RestingWithinDeadband(..., EurUsd_L0DeadbandSpreadRef())` | **No change** | Deadband width still vol-scaled independently of eased quote width |
| Add / Reload / exit geometry | **No change** | Unchanged per ADR-097 negative space |

**Answer:** Easing applies to the **same BC sigma term** as GBPUSD (`sigma` from `V2_FvSigmaFromCloses` on EURUSD M5 closes). No separate vol-scale handling is required for `dynamic_hs` because vol-scale never modified the sigma path on EURUSD. Easing narrows `sigma * effective_multiplier`; deadband continues to use its own vol-scaled reference spread — orthogonally.

**Observability consequence:** `l0_lag` `deadband_skip` on EURUSD calls `V2_L0RestingWithinDeadband` **with** `EurUsd_L0DeadbandSpreadRef()` so logged skip flags match actual replace-gate behavior (GBPUSD omits the fifth argument because its ref is 0).

## Decision

Port ADR-097 design into `fxmatrix_v2_eurusd.mq5`:

### 1. Production inputs (`fxmatrix_v2_eurusd.mq5`)

| Input | Production default | Role |
|-------|-------------------|------|
| `InpEaseDepthStart` | **1** | Opposite depth ≤ this → full `InpSpreadMultiplier` |
| `InpEaseDepthFull` | **4** | Opposite depth ≥ this → `InpSpreadMultiplierEased` |
| `InpSpreadMultiplier` | 0.5 | Un-eased multiplier (unchanged) |
| `InpSpreadMultiplierEased` | 0.0 | Floor multiplier at full opposite depth (unchanged) |
| `InpPassivityBuffer` | 0.5 pips | Added to live spread in floor term (unchanged) |

**Calibration history:** Discovery-sample defaults were **2/5** (mirroring the GBPUSD discovery analysis). A four-window × six-config threshold sweep (24 EURUSD backtests, ADR-098 binary throughout) compared no-op (`InpSpreadMultiplierEased = InpSpreadMultiplier`), discovery default 2/5, tighter 1/3, middle 1/4, wider 1/5, and wider 2/6 across `truss_crisis`, `q1_2024_chop`, `vaccine_rally`, and `full_quarter`.

**Locked calibration (2026-07-29, Gemini approved):** **1/4** replaces 2/5 as EURUSD production default.

**Rationale — scalp count, not turnover-per-exposure:**

- FXMatrix V2 EURUSD is a **fixed-target (3 pip), fixed-lot (0.01) churn** business on a $10,000 account. Completed round-trip count is the primary revenue driver when per-scalp economics are stable.
- **1/4 (tighter than discovery 2/5)** produced **1,746 total exits** across the four canonical windows vs **1,597 under 2/5 (discovery default easing)** — **+149 scalps (+9.3%)** — with aggregate in-test P&L **$450.71 vs $412.99** (+$37.72).
- Per-window peak exit counts: `truss_crisis` and `full_quarter` peak at **1/4** (726 and 301 exits); `q1_2024_chop` and `vaccine_rally` peak at **1/3** (371 and 360). **1/4 wins on aggregate** scalp count and P&L across all four windows simultaneously.
- **Wider-ramp hypothesis retracted:** Configs **1/5** and **2/6** (slower ramp to eased multiplier) were tested on the hypothesis that a wider ramp might improve churn on EURUSD's vol-scaled deadband pair. Sweep showed mixed per-window deltas vs 2/5 — not uniformly better — and **lower aggregate exits and P&L than 1/4**. Wider ramp is not adopted.
- An earlier informal ranking by **P&L ÷ time-avg|net lots|** (turnover-per-exposure) is **retracted** for the same reasons as ADR-097: at 0.01 lots on this account size, raw P&L and scalp count are the operative comparators.

**Manual Strategy Tester verification (Khalid, 2026-07-29):** Independent override runs at **1/4** on canonical windows **Truss Crisis** ($188.79, 726 exits) and **Q1 2024 Chop** (matching sweep reference figures) before source-default lock-in.

**Same-binary no-op baseline:** Threshold-sweep comparisons use ADR-098 binary with `InpSpreadMultiplierEased = InpSpreadMultiplier` (ramp neutralised). The passivity floor (`MathMax` on half-spread) remains active.

### 2. Effective multiplier ramp (flat side only)

When quoting side is flat (`ArraySize(g_*_layers) == 0`):

- Long L0: `opposite_depth = ArraySize(g_short_layers)`
- Short L0: `opposite_depth = ArraySize(g_long_layers)`

```mq5
if(opposite_depth <= InpEaseDepthStart)
    effective_multiplier = InpSpreadMultiplier;
else if(opposite_depth >= InpEaseDepthFull)
    effective_multiplier = InpSpreadMultiplierEased;
else
    double frac = (double)(opposite_depth - InpEaseDepthStart) / (double)(InpEaseDepthFull - InpEaseDepthStart);
    effective_multiplier = InpSpreadMultiplier - frac * (InpSpreadMultiplier - InpSpreadMultiplierEased);
```

When quoting side has open layers, `effective_multiplier = InpSpreadMultiplier` unchanged (Add/Reload/exit geometry untouched).

**Production example (1/4, mult=0.5, eased=0.0):**

| opposite_depth | effective_multiplier |
|----------------|---------------------|
| 0, 1 | 0.500 |
| 2 | 0.333 (⅓ eased) |
| 3 | 0.167 (⅔ eased) |
| ≥ 4 | 0.000 |

### 3. Inlined BC signal functions (replace `V2_ComputeBcBid` / `V2_ComputeBcOffer` delegation)

`Long_ComputeBidSignal` / `Short_ComputeOfferSignal` mirror GBPUSD ADR-097:

- Same FV/sigma from M5 closes `[6]`, `[12]`, `[48]`
- `effective_multiplier = V2_EffectiveSpreadMultiplier(...)` when quoting side flat
- `live_spread_price = V2_L0ResolveLiveSpreadPrice(InpQuoteSpread)` (static `g_last_valid_spread_price` sentinel)
- `dynamic_hs = V2_L0DynamicHalfSpread(quote, sigma, effective_multiplier, live, passivity_buffer)`
- `(double)` cast on ramp fraction inside `V2_EffectiveSpreadMultiplier` (shared helper from ADR-097)

`V2_ComputeBcBid` / `V2_ComputeBcOffer` in `fxmatrix_v2_signal.mqh` remain **unchanged** (EURGBP and other callers unaffected).

### 4. DIAG observability

Same format as GBPUSD, gated `InpVerboseLog && opposite_depth > InpEaseDepthStart`:

- `event=l0_ease` inside signal functions (flat side only)
- `event=l0_lag` in `Long_OnNewBar` / `Short_OnNewBar` before replace (with EURUSD vol-scale deadband ref on skip probe)

### 5. OnInit guard

```mq5
if(InpEaseDepthFull <= InpEaseDepthStart || InpEaseDepthStart < 0 || InpEaseDepthFull < 0)
    return INIT_FAILED;
```

### 6. Unit tests (`fxmatrix_v2_tests.mq5`)

Shared ADR-097 helper tests cover ramp, floor, and live-spread fallback. EURUSD production lock adds:

- `Test_L0SpreadEaseMultiplierRamp_Production14` — **locked 1/4 production thresholds** (EURUSD)

Discovery 2/5 ramp remains in `Test_L0SpreadEaseMultiplierRamp` (regression).
