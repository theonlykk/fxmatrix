# ADR-051 — SNIPER Order Expiry

**Status:** Committed

## Context

SNIPER single-sided limits accumulated as stale resting orders when market moved away from dislocation. Ticket 483094473 (EURUSD SELL @ 1.14087) remained unfilled at 2026-06-26 week close.

## Decision

Add `SniperExpiryBars=1` input; query `ORDER_TIME_SETUP` from MT5 broker natively — stateless, no custom global array, survives VPS reboots; cancel unfilled SNIPER limit after N bars on each new-bar evaluation.

## Consequences

SNIPER limits expire within 1 bar (5 minutes) by default; slot resets cleanly; fresh signal evaluated next bar; restart-safe by design.

## Negative Space

MM quoting loop unchanged; execution engine unchanged; no global state added; no impact on filled positions.
