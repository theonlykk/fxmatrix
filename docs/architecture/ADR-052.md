# ADR-052 — Multi-Timeframe Term Structure

**Status:** Committed (Step A — logging only; Step B — execution wiring; Step C — dynamic spread & sigmoid sizing)

## Context

Static 12-bar anchor is arbitrary; Phase 2 introduces multi-timeframe term structure to measure fair value agreement across 30min/1hr/4hr horizons.

## Decision (Step A)

`ComputeTermStructure()` computes FV_combined (weighted 0.50/0.30/0.20) and sigma_FV (dispersion in points) for AC and BC slots; logging only, no execution wiring yet.

## Step B — Execution Wiring (committed)

- `g_fv_combined[]`, `g_sigma_fv[]`, `g_sigma_fv_pts[]` globals added to `Globals.mqh`
- `ComputeTermStructure()` writes results to globals before logging
- `ComputeTermStructure()` call moved to before anchor assignment in `RunSignalOnBarClose()`
- `g_anchor[]` and `g_r_signal[]` now use blended anchor: `MathLog(ac_now / g_fv_combined[0])` etc.

## Step C — Dynamic Spread & Sigmoid Sizing (committed)

**Parameters:** `SpreadMultiplier=0.5`, `SigmoidMaxScale=3.0`, `SigmoidMidpoint=50.0` pts, `SigmoidSteepness=0.15`

**Dynamic half-spread:**
```
dynamic_half_spread = QuoteSpread + (g_sigma_fv[slot] * SpreadMultiplier)
```
SLOT_AB uses `MathMax(g_sigma_fv[0], g_sigma_fv[1])` — weakest-link survival.

**Sigmoid lot multiplier:**
```
lot_multiplier = 1.0 + (SigmoidMaxScale - 1.0) / (1.0 + exp(k * (sigma_pts - midpoint)))
clamped to [1.0, SigmoidMaxScale]
```
Applied in `ComputeLDAKLotSize()` after the 70% binary gate passes.

**Wiring:** MM quoting block and Phase 3 resume use `ComputeDynamicHalfSpread(inst)`. ADR-037 baseline fallback and spatial deadband retain fixed `QuoteSpread`. SNIPER block and grid spacing (`ComputeNextLayerPrice`, `HandleEntryFill`) unchanged.

## Consequences

All downstream pricing uses blended anchor (Step B). Quote half-spread widens with dispersion; lot size scales up when timeframes agree (up to 3× at σ≈0), decays to baseline at high dispersion. Phase 2 Shared Brain complete.

## Negative Space

`ac_now`/`bc_now` unchanged. ADR-037 fallback and deadband use fixed `QuoteSpread`. SNIPER, exit geometry, and grid add-spacing unchanged. No new globals in Step C.
