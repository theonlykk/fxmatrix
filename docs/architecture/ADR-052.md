# ADR-052 — Multi-Timeframe Term Structure (Step A — Logging Only)

**Status:** Committed (Step A — logging only)

## Context

Static 12-bar anchor is arbitrary; Phase 2 introduces multi-timeframe term structure to measure fair value agreement across 30min/1hr/4hr horizons.

## Decision

`ComputeTermStructure()` computes FV_combined (weighted 0.50/0.30/0.20) and sigma_FV (dispersion in points) for AC and BC slots; logging only, no execution wiring yet.

## Consequences

DIAG logs now show term structure on every M5 bar; zero execution impact; Step B will wire FV_combined into anchor, Step C will implement dynamic spread and sigmoid sizing.

## Negative Space

g_anchor unchanged; g_r_signal unchanged; no globals added; no execution path modified.
