# ADR-052 — Multi-Timeframe Term Structure

**Status:** Committed (Step A — logging only; Step B — execution wiring)

## Context

Static 12-bar anchor is arbitrary; Phase 2 introduces multi-timeframe term structure to measure fair value agreement across 30min/1hr/4hr horizons.

## Decision (Step A)

`ComputeTermStructure()` computes FV_combined (weighted 0.50/0.30/0.20) and sigma_FV (dispersion in points) for AC and BC slots; logging only, no execution wiring yet.

## Step B — Execution Wiring (committed)

- `g_fv_combined[]`, `g_sigma_fv[]`, `g_sigma_fv_pts[]` globals added to `Globals.mqh`
- `ComputeTermStructure()` writes results to globals before logging
- `ComputeTermStructure()` call moved to before anchor assignment in `RunSignalOnBarClose()`
- `g_anchor[]` and `g_r_signal[]` now use blended anchor: `MathLog(ac_now / g_fv_combined[0])` etc.

## Consequences

All downstream pricing (`InvertSpreadToPrice`, `ComputeEntryPrice`, cooldown drag, Phase 3 resume) automatically uses blended anchor; quote prices now reflect weighted 30min/1hr/4hr consensus. DIAG logs show term structure on every M5 bar. Step C will implement dynamic spread and sigmoid sizing.

## Negative Space

`ac_now`/`bc_now` unchanged; `ac_1h`/`bc_1h` still computed (ADR-044) but no longer assigned to `g_anchor[]`. Dynamic Spread and Sigmoid sizing deferred to Step C.
