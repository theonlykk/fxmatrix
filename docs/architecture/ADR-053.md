# ADR-053 — Closed Pod Telemetry Accuracy

**Status:** Committed

## Context

The Pipshed closed-trades table was not displaying records reliably. Three root causes were identified in the `EmitPodClose()` path:

1. **UTC vs broker date mismatch** — `close_time` was emitted in UTC (`TimeGMT()`), while the frontend filtered by broker session date, causing trades near midnight to fall on the wrong calendar day.
2. **Planned price logged instead of actual fill** — `CurL.exit_target` (the LIFO unwind limit target) was passed as `exit_price`, not the actual deal fill price from MT5 history.
3. **`layers_closed` hardcoded to 1** — multi-layer pods reported a single layer regardless of inventory depth at close.

## Decision

### `TelemetryEngine.mqh` — `EmitPodClose()`

- Add a `trade_date` field to the JSON payload, derived internally from `TimeCurrent()` (broker local time), formatted as `YYYY-MM-DD`.
- Insert `trade_date` between `close_time` and `instrument` in the payload.
- `close_time` remains UTC ISO-8601 for precise timestamping; `trade_date` is the broker session date for frontend date filtering.
- `EmitPodClose()` signature is unchanged — `trade_date` is derived inside the function.

### `ExecutionEngine.mqh` — `HandleExitFill()`

- Add `double deal_price` parameter to `HandleExitFill()`, positioned between `deal_profit` and `hedge_position_ticket`.
- Both `OnTradeTransaction()` call sites pass `deal_price` explicitly (already retrieved via `HistoryDealGetDouble(deal_ticket, DEAL_PRICE)`).
- `EmitPodClose()` call site inside `HandleExitFill()`:
  - Pass `deal_price` (actual fill) instead of `CurL.exit_target` (planned limit).
  - Pass `inv_size` (current inventory array size for the instrument slot) instead of hardcoded `1` for `layers_closed`.

## Consequences

- Closed-trades table displays records on the correct broker session date.
- Exit price in telemetry reflects the actual MT5 deal fill, enabling accurate P&L reconciliation.
- Layer count reflects pod inventory depth at close time rather than a fixed constant.
- `HandleExitFill()` signature now carries the actual exit price, available for future analytics without re-querying deal history.
- No changes to `EmitTelemetry()`, `SerializePodJSON()`, `HandleEntryFill()`, or Pipshed backend in this ADR.
