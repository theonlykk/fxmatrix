# ADR-060 — Cooldown Drag Layer 0 Only

**Status:** Committed

## Context

ADR-046 `RunSpreadCooldownReconciliation()` drags resting entry limits toward the current ideal price as `g_cooldown_LDAK` decays after volatility spikes. ADR-057 kinetic spacing sets add_next layer prices at geometric intervals from the deepest filled layer.

On 2026-06-30 live trading, these two mechanisms collided: cooldown drag applied to **all** pending entry orders matching `EA_MAGIC` and `EA_MAGIC+1`. Four EURUSD add_next layers spread across 107 pips were repeatedly dragged toward market as volatility cooled, collapsing to within 2.7 pips — defeating the Kinetic Gate's spatial component entirely.

## Decision

Restrict cooldown drag to **Layer 0 entries only** (`EA_MAGIC`). Remove `EA_MAGIC+1` (add_next) from the reconciliation filter.

```mql5
// Before (ADR-046):
if (magic != EA_MAGIC && magic != EA_MAGIC + 1) continue;

// After (ADR-060):
if (magic != EA_MAGIC) continue;  // Layer 0 entries only
```

## Rationale

| Role | Magic | Cooldown drag |
|------|-------|---------------|
| Layer 0 — "The Scout" | `EA_MAGIC` | **Yes** — must stay elastic, track cooling volatility |
| add_next — "The Grid" | `EA_MAGIC+1` | **No** — structural defense nodes hold kinetic-computed spacing until filled or restituted (ADR-056) |
| Exit limits | `EA_MAGIC+2` | Never included — separate carry rollover path (ADR-045) |

## Consequences

- Kinetic spacing preserved through volatility cycles
- Grid integrity maintained across cooldown decay
- Layer 0 still tracks cooling volatility as originally designed in ADR-046
- Exit limit dragging (ADR-045) unaffected — separate function, separate magic

## Negative Space

- `ideal_bid` / `ideal_offer` computation untouched
- Freeze level clamp (ADR-048) untouched
- BUY_LIMIT / SELL_LIMIT drag direction checks untouched
- No other files or `EA_MAGIC+1` filter sites modified
